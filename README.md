# 3D-Platformer-ml-agents-RL

This project uses Unity Hub with the ML-Agents module to train an agent to beat a simple 3D-platformer game.

## Project Summary

This project implements a **Deep Q-Network (DQN)** agent using the **Unity ML-Agents Toolkit** [1] to navigate a 3D platformer environment. The agent uses a 16-dimensional observation vector and a balanced reward function to develop survival and target-seeking behaviors [1].

## Prerequisites & Installation

Please refer to the official {Link: Unity Documentation https://unity3d.com}.

## Getting Started

Open the Unity scene and start training once configured.
